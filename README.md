# User-experience-D279

WGU D279 User Experience class project website: a small multi-page site
exploring layout, navigation, and styling for a pet-themed topic.

## Pages (planned)

- `Home.html` — landing page with site navigation
- `Cats.html`, `Dogs.html`, `Fish.html` — topic pages
- `Contact.html` — contact form
- `style.css` — shared site stylesheet

## Status

Pages and stylesheet are currently placeholders; content is being built out
as the course progresses.
